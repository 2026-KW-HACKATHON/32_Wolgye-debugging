# 차곡차곡 — 32_Wolgye-debugging

2026 KW HACKATHON 32조 **월계디버깅** · 세부주제: 배리어프리·생활편의

> "우리 빌라에 주차된 차량을 효율적으로 관리하고, 빈자리를 이웃과 나누는 플랫폼"

좁은 골목 빌라의 이중주차(앞뒤로 겹치는 주차)에서 이웃끼리 **출차 시간**을 미리 나눠 막힘을 줄이고,
남는 **빈자리**는 같은 골목 이웃 빌라와 나누는 지역 서비스입니다.

## 문제

우리 빌라는 심한 이중주차인데, 옆 빌라엔 빈자리가 있습니다.

- 빌라 주차장은 앞차가 빠져야 뒤차가 나올 수 있는 구조입니다. 주차장법상 5대 이하 주차장은 세로 2대 배치가 허용되어 구조 자체는 합법이지만, "누가 언제 나가는지" 공유할 방법이 없어 이른 아침 전화·초인종으로 차를 빼 달라고 요청하다 갈등이 반복됩니다.
- 월계1동 빌라는 세대당 주차면이 **0.40면**(2,468세대, 986면)이라 이중주차가 불가피합니다.
- 서울시 주택가 주차장 확보율은 아파트를 포함하면 103.6%지만 공동주택을 빼면 **63.6%**(2020)로, 빌라촌의 부족은 통계에 가려져 있습니다.

| 조사 | 결과 |
| --- | --- |
| 현장 설문 (유효 15명) | 차량 소유자 6명 중 **5명(83%)** 최근 한 달 새 출차가 막힌 경험 |
| 현장 설문 (시간대 응답 5명) | **5명 전원** 이른 아침(6~9시) |
| 현장 설문 (최다 불편) | 기다림이 아닌 이른 아침·늦은 밤 **연락의 미안함** (3명) |
| 현장 설문 (차량 비소유 6명) | 골목 통행 불편 경험 4명 |
| 인터뷰 | 전화를 받지 않아 초인종을 누르거나, 옆 빌라에 댔다가 관리인과 다툰 경험. 정작 옆 빌라 자리는 일주일째 비어 있었다는 증언 |
| 온라인 설문 (53명) | 공유 주차 시 '예약 시간에 자리가 확실히 비는지' 25명, '소유자 허락·이용 권한 확인' 17명, '진입 공간' 19명, '정확한 위치' 14명이 중요하다고 응답 |

## 해결 아이디어

'내 빌라'에서 '우리 골목'으로, 출차 시간과 빈자리를 나눕니다.

- **목적 1 — 이중주차, 막히기 전에 푼다**: 출차 시간을 올리면 먼저 나갈 차가 바깥쪽에 서도록 칸을 추천하고, 전날 밤 10시에 미리 알립니다.
- **목적 2 — 남는 칸은 이웃과 나눈다**: 남는 칸을 인증된 골목 이웃과 토큰으로 나눕니다.

## 핵심 기능

| 목적 | 기능 | 설명 |
| --- | --- | --- |
| 이중주차 대비 | 이웃의 출차 시간 확인 | 같은 빌라 이웃의 출차 예정 시간을 한눈에 확인 (한 번 / 요일 반복 / 장기 주차) |
| | 자리 추천 · 전날 밤 알림 | 덜 막히는 칸을 추천하고, 내일 나갈 차를 막고 있으면 전날 밤 알림 |
| | 원탭 이동 요청 | 전화번호를 주고받지 않고 앱에서 막는 차 차주에게 이동 요청 |
| | 입체 배치도 | 칸 위치와 앞뒤 순서, 골목 입구를 입체 배치도로 안내 |
| 공유주차 | 골목 공유 주차 | 가까운 옆 빌라의 빈 칸을 찾아 토큰으로 이용 신청, 관리인이 수락 |
| | 미등록 차량 제보 | 사진으로 제보하면 +500 토큰 (하루 3회) |
| | 관리자 대시보드 | 칸별 차량 · 공유 요청 · 혼잡도 관리, 칸 사용 여부 설정 |

## 차별성

- **사후 대응 → 사전 예방**: 빌라 관리 앱 'Capl'이 막힌 뒤의 알림·연락을 돕는다면, 차곡차곡은 출차 시간을 미리 모아 자리 추천·전날 밤 알림으로 막힘 자체를 줄입니다.
- **출차 기록이 곧 공유 근거**: 소유자가 시간을 정해 판매하는 방식과 달리, 쌓인 출차 기록으로 '언제 비는지'를 보여 줍니다.
- **낯선 외부인이 아닌 골목 이웃**: 빌라 초대 코드로 인증된 이웃에게만 열고, 전화번호를 노출하지 않습니다.
- **주차장 안 자리까지 안내**: 주차장 위치까지만 안내하는 지도와 달리, 처음 가는 빌라 주차장의 칸과 입구를 배치도로 보여 줍니다.

## 동작 원리

- **막힘 판정**: 칸마다 앞 칸(출구 쪽 칸)을 연결해 둡니다. 앞 칸 차가 내 차보다 늦게 나가거나 출차 시간이 없으면(장기 주차·미확인 차량) 막힌 것으로 봅니다.
- **자리 추천**: 막히지도, 남을 막지도 않는 빈 칸 중 가장 안쪽 칸을 추천합니다. 정해진 규칙으로 계산하는 방식입니다.
- **전날 밤 알림**: 매일 22:00(KST) 서버 작업이 내일 출차할 차를 막고 있는 차의 주인에게 알림을 만듭니다. 출차 시간을 앞당기면 막고 있는 차의 주인에게 바로 알립니다.
- **동시성**: 주차 등록은 행 잠금으로, 공유 주차 시간대 겹침은 PostgreSQL EXCLUDE 제약으로 막습니다.
- **개인정보**: 전화번호는 다른 주민에게 공유하지 않고(본인 프로필에서도 `010-****-5678`로 표시), 출차 정보는 같은 빌라 주민만 봅니다.

## 향후 계획

1. **시범**: 설문한 골목의 빌라 3~5곳
2. **검증**: 출차 요청 수 · 공유 이용률 · 분쟁 감소
3. **확장**: 월계1동 전체 → 노원구 빌라 밀집 지역

- **운영**: 월계1동 행정복지센터 · 주민자치회와 협력, 통장 · 관리인을 거점 운영자로, 구청 공유주차 지원사업 연계
- **수익**: 주차 현황 · 출차 요청은 무료, 공유 주차 이용료 일부를 수수료로 · 지자체 운영 플랫폼(B2G)
- **기능**: 안심번호 연동 · 결제 · 쌓인 기록 기반 출차 시간 예측 · 휴대폰 푸시 알림
- **차량**: 블루투스 연결 시 주차 등록 알림 · 입출차 자동 기록
- **신뢰**: 공유 주차 이용 온도로 이웃 간 신뢰도 확보
