# 32_Wolgye-debugging

2026 KW HACKATHON 32조 — **빌라 주차 스택 관리 앱**

좁은 골목 빌라의 종렬(앞뒤로 겹치는) 주차에서, 각자 예상 출차 시간을 공유해
"내가 나갈 때 앞차가 막지 않는 자리"를 고르게 해주는 지역 한정 앱입니다.

## 문제

- 빌라 주차장은 앞차가 빠져야 뒤차가 나올 수 있는 LIFO 스택 구조입니다.
- 주차장법상 5대 이하 주차장은 세로 2대 배치가 허용되어 구조 자체는 합법이지만, "누가 언제 나가는지" 공유할 방법이 없어 전화로 차를 빼달라고 요청하다 갈등이 반복됩니다.
- 기존 서비스(모두의주차장 등)는 빈 **공간**을 공유하지만, 우리는 **출차 시간**을 공유합니다.

## 서비스 범위

- 지역: 서울 노원구 월계1동, 그중에서도 좁은 골목의 빌라 부설주차장(사유지)를 목표로 합니다.
- 노상(골목) 주차는 다루지 않습니다. 불법이며 소방 진입로 문제와 얽혀 있습니다.

## 핵심 아이디어

- 주차장은 여러 개의 lane(열)으로 이루어지고, 각 lane은 스택입니다. (position 0이 가장 안쪽)
- **불변식**: 안쪽으로 갈수록 예상 출차 시간이 늦어야 합니다.
- **입차 안전 판정**: 내 예상 출차 시간이 해당 lane 맨 바깥 차의 예상 출차 시간 이하이면 안전합니다.
- **lane 추천**: 안전한 lane 중 맨 바깥 차와 출차 시간 차이가 가장 작은 lane을 추천합니다. 여유가 큰 lane을 아껴 나중에 늦게 나가는 차를 받기 위함입니다.
- **동시성**: 같은 lane에 동시 입차 시 순서가 꼬이지 않도록 lane 단위 잠금 트랜잭션으로 처리합니다.

## 주요 기능 (MVP)

1. 빌라 초대코드로 가입 (건물 단위 신뢰 확보)
2. 주차장 레이아웃 화면: 위에서 내려다보는 2D 뷰, 칸마다 상태 색상 표시
3. 입차 등록: 칸 선택 + 예상 출차 시간 입력
4. 자리 추천: 안전한 칸 표시, 막히는 칸 경고
5. 알림: 앞차 출차 임박, 내 차가 남을 막고 있음, 이동 요청 수신
6. 이동 요청: 전화번호 노출 없이 앱 내에서 "차 빼주세요" 전송
7. 미등록 차량: "출차 시간 미상" 차량으로 칸에 등록

### 확장 기능 (여유가 있으면)

- 인근 여유 빌라의 유휴 주차면 유료 대여 (건물 소유자/관리자가 등록하는 흐름만 허용)
- 출차 시간 준수율 기반 신뢰도 표시

## 제약 / 원칙

- API 키를 앱에 하드코딩하지 않으며, LLM 호출은 백엔드를 경유합니다.
- 로드뷰 이미지를 저장하거나 가공하지 않습니다 (지도사 약관 위반 소지).
- GPS로는 칸 판별이 불가능(오차 5~10m)하므로 칸 확정은 사용자가 직접 선택합니다.
- 차량번호는 마스킹해서 저장/표시하고(예: `12가 ****`), 전화번호는 노출하지 않습니다.
- 3D 모델링, 실결제, 마이크로서비스는 범위 밖입니다.
